Common questions

Questions about networking and structured cabling

Do IP CCTV cameras need a network?

Yes. IP cameras transmit video over data networks. Using PoE switches, they receive both data and power over a single cable.

What cable type is used?

We use standard CAT5e and CAT6 cables supporting Gigabit Ethernet. CAT6 is preferred for longer runs and higher data rates.

Can Wi-Fi replace structured cabling?

Wi-Fi is great for mobile devices, but reliability-critical devices like IP cameras always perform better with a physical, cabled connection.

Do you test and label cables?

Yes. We test every cable run to verify data rate capacity, and we consistently label all ports and cables for easy maintenance.
