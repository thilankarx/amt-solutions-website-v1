What access control systems do we install?

We install standalone single-door controllers for smaller applications and fully networked systems that manage multiple doors from a central point.

Our solutions include proximity card readers (RFID), PIN keypads, and fingerprint biometric readers combined with appropriate electric door hardware.

What an access control system can include

  • RFID card / fob access readers
  • Fingerprint biometric readers
  • PIN keypad entry
  • Electromagnetic door locks
  • Electric strike locks
  • Door sensors and exit buttons
  • Access controller and management software
  • Access event logging
  • User credential management
  • Time-zone access scheduling
  • Expansion for additional doors

What to consider before installing access control

Door type

Door hardware compatibility

We assess your door material and frame to specify the correct electric locks, ensuring whether fail-safe or fail-secure operation is required.

Number of doors

Standalone vs networked

A single entry point can use a standalone controller, while multi-door setups benefit from a networked system for centralized logging and management.

Credential type

Card, biometric or PIN

Card systems are great for general office access, while biometric systems prevent credential sharing for higher security areas.

Integration

Integration with CCTV

Access control events can be correlated with CCTV footage. We coordinate the network and cabling requirements for unified security installations.

Common questions

Questions about access control

Can access control be integrated with CCTV?

Yes. We frequently install cameras at controlled entry points so entry logs can be cross-referenced with video footage.

What happens if the power fails?

Electromagnetic locks are typically fail-safe (release on power loss), while electric strikes are fail-secure. We evaluate this based on fire safety requirements.

Can access be restricted by time?

Yes, networked systems support time-zone scheduling, allowing access only during specific work hours or shifts.

Can an existing system be expanded?

It depends on the controller's capacity. We can assess your existing setup and advise on expansion or replacement.
