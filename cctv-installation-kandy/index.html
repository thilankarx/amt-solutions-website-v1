Design considerations

What we consider before installing CCTV

A CCTV system that performs well in real conditions requires attention to several site-specific factors before cameras are placed or equipment is ordered.

Coverage

Camera coverage and blind spots

Camera positions are determined by which areas need to be observed or identified. The aim is to reduce unmonitored zones, particularly around entry points, high-risk areas and property boundaries.

Lighting

Day and night visibility

Lighting conditions affect image quality significantly. Areas with limited light require cameras with infrared capability or supplementary lighting. Different times of day may produce different results, which is assessed during the site visit.

Distance

Viewing distance and detail

A camera intended to monitor a wide area differs from one that needs to identify faces or vehicle registration details at a distance. Lens selection and camera resolution depend on what level of detail is required.

Storage

Recording duration and capacity

Required storage depends on the number of cameras, resolution, frame rate, compression method, recording mode (continuous or motion-triggered) and how many days of footage need to be retained.

Network

Network infrastructure

IP camera systems depend on network switches, PoE capacity, bandwidth and structured cabling. AMT Solutions assesses existing infrastructure and can install or upgrade the network as part of the CCTV project.

Power

Power supply and backup

Reliable power is essential. Where continuous recording is required, UPS backup and surge protection should be considered so the system continues operating during power interruptions.

Can I view my CCTV cameras from my phone?

Many modern CCTV systems can be configured for secure remote viewing from supported mobile applications. This allows property owners and managers to check live camera feeds and review recorded footage from a smartphone or tablet.

Availability of remote viewing depends on:

  • The CCTV platform and manufacturer app support
  • A stable internet connection at the installation site
  • Correct network and port configuration
  • Security settings on the recorder and network

AMT Solutions configures remote viewing as part of the installation process and sets up the mobile app on the client's device during handover.

Can existing CCTV systems be upgraded?

In many cases, an older CCTV system can be partially or fully upgraded rather than replaced entirely. Whether existing components can be reused depends on:

  • Current camera technology (analog, HD, IP)
  • Condition and type of existing cabling
  • Recorder compatibility (DVR vs NVR)
  • Power infrastructure condition
  • Network availability for IP upgrades

AMT Solutions inspects the existing system before recommending an upgrade path. In some situations, analog systems can be upgraded to HD using the same coaxial cables. Moving to IP CCTV typically requires new network cabling.

IP CCTV vs HD analog CCTV

Both IP and HD analog CCTV systems can produce high-quality surveillance footage. The right choice depends on the property's existing infrastructure, required features and budget.

Key differences

  • IP CCTV — uses network cables (CAT5e/CAT6) and PoE switches. Supports higher resolutions and advanced features such as analytics. Requires network infrastructure.
  • HD analog — uses coaxial cables. Suitable for upgrading existing analog cabling to HD quality. Generally simpler to install where coaxial runs already exist.
  • Recorder — IP systems use NVR (Network Video Recorder). Analog systems use DVR (Digital Video Recorder).
  • Scalability — IP systems are typically easier to expand by adding PoE ports. Analog systems are limited by DVR channel count.
  • Cost — HD analog can be more cost-effective for smaller installations. IP may offer better long-term value for larger or expandable systems.

AMT Solutions recommends the system type based on your site conditions, existing cabling and requirements — not a one-size-fits-all preference.

Common questions

CCTV installation questions — Kandy

How much does CCTV installation cost in Kandy?

CCTV installation cost in Kandy depends on the number of cameras, system type (IP vs HD analog), resolution, storage capacity (hard drive size), cabling distance, and site characteristics. AMT Solutions conducts a site assessment to provide an accurate, transparent quotation tailored to your property requirements.

How many CCTV cameras do I need?

The number of cameras depends on the property layout, the areas that need coverage, required viewing distance, lighting conditions and the level of detail needed. A site assessment is the most reliable way to determine camera quantity and placement for your specific property.

Can I view CCTV cameras from my phone?

Most modern CCTV systems support remote viewing via a mobile app, provided the installation site has a stable internet connection. AMT Solutions configures remote viewing and sets up the app on your device as part of the installation handover.

Do you install CCTV systems for businesses in Kandy?

Yes. AMT Solutions provides commercial CCTV installations for retail shops, offices, warehouses, factories, hotels, schools, apartment properties, and commercial buildings in Kandy with multi-camera NVR recording, multi-user permissions, and extended retention.

Can AMT Solutions upgrade an existing CCTV system?

In many cases, existing systems can be partially or fully upgraded. Whether components can be reused depends on the current camera technology, cabling type, recorder and infrastructure condition. AMT Solutions inspects the existing system before recommending an upgrade path.

What type of CCTV camera should I choose?

The camera type depends on its intended purpose. Dome cameras suit indoor or covered areas, bullet cameras are common for outdoor use, and PTZ cameras allow remote directional control. AMT Solutions recommends camera types based on site conditions rather than a standard selection.

Can CCTV cameras work at night?

Yes. Cameras with infrared (IR) capability can capture footage in low-light or complete darkness. The effective IR range varies by camera model. During the site assessment, AMT Solutions evaluates lighting conditions to specify cameras with appropriate night-vision capability.

How long can CCTV footage be stored?

Recording duration depends on the number of cameras, resolution, frame rate, compression method, recording mode and hard drive capacity. Systems can be configured to retain footage for a specific number of days before overwriting. Storage requirements are calculated during the system design phase.

Do CCTV systems need internet access?

No. Local recording and live viewing on the same network work without internet. However, remote viewing from outside the property (via a mobile app) requires an internet connection at the installation site.

Can CCTV continue working during a power failure?

Only if the system is connected to a UPS (Uninterruptible Power Supply). AMT Solutions can size and install a UPS to keep cameras and recorders running during power interruptions. The duration of backup depends on the UPS capacity and system power draw.

What information is needed for a CCTV quotation?

To provide an accurate quotation, AMT Solutions typically needs the property location, property type (home, shop, office, etc.), approximate number of areas to cover, whether an existing system is installed, and any specific requirements such as remote viewing or extended recording.

Is a site visit required before installation?

A site visit is strongly recommended. It allows AMT Solutions to assess camera positions, cabling routes, network infrastructure, lighting and power — all of which affect the system design. Installations specified without a site visit may not perform as expected.
