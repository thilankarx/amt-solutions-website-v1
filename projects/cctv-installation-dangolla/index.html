CCTV Installation Project in Dangolla, Kandy

AMT Solutions completed a CCTV surveillance installation for a residential property in Dangolla, near Kandy. The project used smart security cameras with custom protective housings designed for the local environment.

Project overview

  • Location: Dangolla, Kandy
  • Property type: Residential
  • Service: CCTV surveillance installation
  • Equipment: EZVIZ smart security cameras

Installation details

The CCTV system was installed to provide surveillance coverage for a residential property in Dangolla, a suburb near Kandy city.

A notable feature of this installation was the use of specially designed iron protective boxes for the outdoor cameras. These housings were fabricated to guard against external impacts and damage — a practical consideration in the Dangolla area where wildlife, including monkeys, can interfere with exposed camera equipment.

The system uses EZVIZ smart security cameras, which support remote viewing via a mobile application, allowing the property owner to monitor the premises when away from home.

Installation considerations

Several site-specific factors were addressed during this project:

  • Camera protection — Custom iron housings to prevent physical damage from wildlife and weather
  • Outdoor durability — Equipment selected and mounted for long-term outdoor exposure
  • Remote viewing — System configured for secure mobile app access
  • Coverage planning — Camera positions selected to cover key areas of the property
