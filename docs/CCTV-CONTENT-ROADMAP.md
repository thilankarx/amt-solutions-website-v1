## Priority 2 — Medium Impact (Create within 3–6 months)

### 4. How many CCTV cameras does a property need?
**Type:** Guide / blog post
**Target keywords:** "how many CCTV cameras", "CCTV camera count", "cameras for house"
**Content direction:**
- Explain that camera count depends on property layout, coverage requirements, and viewing distance
- Use practical examples (2-bedroom home vs. commercial warehouse)
- Include a "site assessment is the best way to determine" CTA
- Do NOT publish generic camera-count tables without context

### 5. IP CCTV vs analog CCTV — detailed guide
**Type:** Guide / blog post
**Target keywords:** "IP vs analog CCTV", "IP camera vs coaxial", "NVR vs DVR"
**Content direction:**
- Expand on the compact section in the Kandy page
- Include infrastructure considerations (cabling, PoE, switches)
- Discuss upgrade paths from analog to IP
- Keep balanced — do not declare one universally superior

### 6. How much recording storage does CCTV require?
**Type:** Guide / blog post
**Target keywords:** "CCTV storage calculator", "how long does CCTV record", "NVR hard drive size"
**Content direction:**
- Explain the variables: camera count, resolution, frame rate, compression, recording mode
- Provide general guidance without publishing fake storage tables
- Recommend calculating during system design phase

### 7. Remote CCTV viewing explained
**Type:** Guide / blog post
**Target keywords:** "view CCTV on phone", "remote CCTV app", "CCTV mobile viewing"
**Content direction:**
- Explain how remote viewing works (internet, port forwarding, P2P, cloud)
- Discuss security considerations
- Note that availability depends on the platform

## Content Guidelines

1. **No fabricated technical specifications** — if exact numbers are needed, calculate them or mark as pending
2. **No keyword stuffing** — write naturally for the reader
3. **No superlative claims** — no "best", "cheapest", "#1"
4. **Site assessment CTA** — every piece of content should include a path to requesting a site visit
5. **Internal linking** — every new content piece should link to the Kandy landing page and relevant service pages
6. **AIEO readiness** — write clear, self-contained sentences that AI search engines can extract as answers
7. **Real evidence** — include project photos and examples wherever available
